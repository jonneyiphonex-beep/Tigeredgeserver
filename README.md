# 🐅 Tigeredgeserver (Air-Gapped Offline Sovereign Edge)

**Tigeredgeserver** هو نظام تشغيل خادم حافة (Edge Server) مدمج ومستقل، مصمم للعمل في بيئات معزولة تماماً عن شبكة الإنترنت الخارجية (Air-Gapped/Offline-First) مع أعلى مستويات الأمان والتشفير.

---

## 📐 الهيكلية المفهومية (Architecture)

يتكون المشروع من عدة مكونات متكاملة لبناء بيئة خادم معزولة ومستقرة:

* **Engine (`cmd/engine`):** محرك الأساس المكتوب بلغة **Rust** لإدارة الذاكرة والعمليات بخفة وأداء عالٍ مع استجابة صفيّة (1ms latency).
* **Gateway (`cmd/gateway`):** بوابة التواصل المحلية المكتوبة بلغة **Go (Golang)** التي توفر نقطة اتصال HTTP محلي آمنة عبر المنفذ `8443`.
* **Hardening Script (`scripts/harden_system.sh`):** سكربت لتأمين النظام وإغلاق ثغرات الاتصال الخارجي عبر إعداد قواعد صارمة لـ `iptables` وتكتيم أجهزة الاتصال اللاسلكي (`rfkill`).
* **Buildroot Integration (`tigeredgeserver.mk`):** ملف حزمة مخصص لبناء وتجميع خادم الحافة المدمج ضمن بيئة Buildroot.

---

## 🔒 السياسات الأمنية (Security Policies)

1. **العزل التام (Air-Gap Isolation):** حظر حركة المرور عبر شبكات WAN الخارجية نهائياً (`block_all_wan = true`).
2. **التشفير القوي:** تشفير قاعدة البيانات المحلية ونقاط التخزين باستخدام خوارزمية `AES-256-GCM`.
3. **التحكم بالشبكة:** السماح بالاتصال فقط عبر الـ Loopback المحلي (`127.0.0.1`) وأجهزة الشبكة المحلية المغلقة (`10.0.0.0/8`).
4. **تقييد الصلاحيات:** تحديد صلاحيات تشغيل برامج النظام إلى القراءة والتنفيذ للـ root فقط (`chmod 500`).
